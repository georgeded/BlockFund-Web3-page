What is BlockFund

A portfolio project you can actually hold

BlockFund was created by a group of computer-science students to learn blockchain end to end: the token contract, the exchange, and the website around them.

It lives on Base Sepolia, a public testnet of Coinbase's Ethereum layer-2. Test tokens have no monetary value, so anyone can experiment freely.
